自主專案

Kizuna 羈絆 ＃自我管理 App

一、專案背景與目標

現代人在工作、課業與生活中，經常需要同時管理待辦事項與培養日常習慣，但多數應用程式僅專注於單一功能，使用者需在不同工具間切換，不僅增加管理成本，也難以長期維持使用，進而影響目標執行與習慣養成。

因此，本專案設計 Kizuna（羈絆），以「陪伴使用者持續成長」為核心理念，打造一款整合待辦管理、習慣養成與目標追蹤的自我管理 App。透過清晰的任務規劃、視覺化進度呈現，幫助使用者降低規劃負擔、提升執行力，逐步建立穩定的生活節奏與良好習慣。

二、執行方式與流程

  1. 前期研究 Discovery 使用 FigJam 進行競品分析
  2. 定義 Define 建立 Persona
  3. 研究使用者體驗／介面設計 User Flow 建立、Wireframe 建立、Design System 視覺設計、Prototype 建立

三、Wireframe 建立

以「待辦事項」與「習慣養成事項」用區段區分，避免使用者混淆；並以數據化面板降低文字使用率，減少閱讀負擔、提升執行率。

四、Design System 建立

建立文字樣式（Noto Sans TC Bold / Regular）、主色與輔助色系統，以及圖示元件庫，確保介面視覺一致性。

五、Prototype 建立

整合 Variables 與 Components，完成可互動的高保真原型。
